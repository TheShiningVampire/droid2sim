# Historical experiment scripts

These are the original one-off scripts from candidate selection, the rejected glossy-mug investigation, and report assembly. They are retained as provenance, not as supported pipeline commands. They assume the old root-file layout and can overwrite current outputs if manually adapted and run.

Use the `droid2sim` package and the stage-specific `scripts/` modules instead. The reports and all five archived results are the authoritative experiment record. In particular, `write_report.py` predates the later SysID and repository-organization addenda; do not use it to regenerate the current report.
